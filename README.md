# 📘 OS Handwritten Notes Generator

Turn dry Operating Systems textbook chapters into beautiful, colorful **handwritten-style PDFs** with automatic Gantt charts, Page Tables, and Inode diagrams.

![Demo](https://via.placeholder.com/800x400?text=OS+Notes+Generator)

## ✨ Features
- 🤖 **AI-Powered**: Uses GPT-4 to extract scheduling, paging, and file system data.
- 🖍️ **Handwritten Rendering**: Realistic handwritten fonts with natural spacing.
- 📊 **OS-Specific Diagrams**:
  - CPU Scheduling Gantt Charts (FCFS/SJF)
  - Page Table Valid/Invalid bit grids
  - Inode direct/indirect pointer structures
- 🎨 **Colorful & Readable**: Color-coded processes, valid/invalid frames, and vibrant accents.
- 📄 **PDF Export**: One-click download of A4-sized study notes.
